add_revision_fields()

class-revisions.php : 108

Add each field to the fields the Revisions screen compares.

public add_revision_fields(array<string, string> $fields[, array<string|int, mixed>|WP_Post|null $post = null ]) : array<string, string>

Filter callback for _wp_post_revision_fields. Core reads these fields from the post object, where they are always empty, so they never count as a change or get written to a post; get_field_text() supplies what the Revisions screen shows.

wp_restore_post_revision() is the only caller that passes a revision, just before it updates the post, so that call also marks the start of a restore for finish_restore().

Parameters
$fields : array<string, string>

Field name => label.

$post : array<string|int, mixed>|WP_Post|null = null

Post whose revisions are compared.

Return values
array<string, string>

finish_restore()

class-revisions.php : 210

Finish restoring a revision.

public finish_restore(int $post_id, int $revision_id) : void

Action callback for wp_restore_post_revision, after core has restored the fields. Core saves a revision while it restores the title, before the fields, so that revision holds the fields as they were before the restore. It is given the restored fields; if no revision was saved, one is saved now, so the latest revision always matches the post.

Parameters
$post_id : int

Post ID.

$revision_id : int

ID of the revision that was restored.
