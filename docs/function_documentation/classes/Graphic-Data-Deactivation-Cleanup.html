class-deactivation-cleanup.php : 18

Prompts for and performs a full data wipe when the plugin is deactivated.

The confirmation and the deletion both happen on the Plugins screen, before the deactivate link is followed. A deactivated plugin's PHP is no longer loaded on subsequent requests, so any admin_notices/admin-post flow tried after deactivation would never run.
