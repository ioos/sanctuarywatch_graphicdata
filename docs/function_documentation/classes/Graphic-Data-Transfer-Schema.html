SCHEMA_VERSION

class-transfer-schema.php : 40

Version of the package format written by the exporter.

public mixed SCHEMA_VERSION = 1

Independent of the plugin version. Increment whenever the structure of manifest.json / content.json or the meaning of a field changes, and add a matching upgrade step to get_upgrades() so older packages remain importable. Adding a field does not need a new version: packages made before it simply do not have it, as posts saved before it do not.

get_import_status()

class-transfer-schema.php : 335

Statuses to give an imported post.

public static get_import_status(string $post_type, string $source_status, bool $hold) : array{post_status: string, publication_status: string}

Graphic Data post types are always published in WordPress terms: their edit screens have no Save Draft button, and the admin only offers published posts as parents. Whether one appears on the site is set by its Graphic Data status field instead, so a held post (or one that was not published in WordPress on the source site) keeps post status 'publish' and has that field set to get_held_publication_status(). Pages use ordinary WordPress statuses.

Parameters
$post_type : string

Post type slug (including 'page').

$source_status : string

WordPress post status on the source site.

$hold : bool

True for a copy of an existing post or a post missing a required parent.

Return values
array{post_status: string, publication_status: string} —

An empty publication_status means keep the exported value.

get_upgrades()

class-transfer-schema.php : 469

Steps that bring an older package's content.json up to SCHEMA_VERSION.

public static get_upgrades() : array<int, callable>

Keyed by the version each step produces: the step for 2 turns version 1 content into version 2 content. A step receives the decoded content array and returns it changed, for example with rename_meta_key() when a field is renamed. Steps must never be edited or removed once released, because packages made with that version may still exist.

array<int, callable>
