get_link_targets()

class-transfer-importer.php : 783

Every link from a package post to content outside the package, each of which the user points at a post on this site (or leaves empty).

private get_link_targets() : array<string, array<string|int, mixed>>

A target is keyed ":<source ID>", so every post linking to the same source post follows one choice. A required parent that was not set on the source site gets its own target, "empty::", so it can be chosen too, unless the post's higher parent is in the package (that parent will be new, so nothing here can belong to it).

Required parents form a chain (Instance, then Scene, then Modal), and each target records the target above it as parent so the choices on offer can be narrowed to what belongs to the chosen parent.

Also fills $required_refs: for each post with required parents, one entry per parent whose key is the target key, '' when the parent is in the package, or 'none' when it is missing and cannot be chosen.

Return values
array<string, array<string|int, mixed>> —

Target key => key, type, source_id, title, required, parent, used_by and suggested (post ID or 0).
