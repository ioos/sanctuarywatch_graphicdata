class-transfer-importer.php

Content Transfer importer.

Imports a package written by Graphic_Data_Transfer_Exporter. An import is a job that runs over several requests so that large packages stay clear of upload and request time limits:

  1. The zip is uploaded in chunks into a private work folder.
  2. The package is validated (format, schema version, checksums) and a dry run works out what will happen on this site, including every link to content outside the package (see get_link_targets()).
  3. The user chooses what each of those links points at on this site (and, for Figures, which Modal tab), then the import runs in steps: media files a few at a time, then all terms, posts, data files and references in one step.

Everything an import creates is tagged with a batch ID so it can be undone, automatically when a step fails or later from the Content Transfer page. An About post that is overwritten is backed up first.

Rules (see Graphic_Data_Transfer_Schema for the fields involved):

  • Every post is created new and assigned to the importing user. A post that already exists here is imported as a copy and held (Status set to Draft). The About post is the exception: it overwrites the existing one.
  • Graphic Data post types are always published in WordPress terms; a held post has its Graphic Data Status field set to Draft.
  • Instance Type terms with the same slug are reused.
  • References are remapped to the imported posts. A reference to content outside the package goes to the post the user chose. The suggested choice is the same post (when this site is the source site), an earlier import of it, or a post of the same type with the same slug. A link left empty is cleared (page block references to 0). A Scene, Modal or Figure left without a required parent is held and reported as an error.
  • Editors may import packages holding a single Figure only.

Administrators can also upload a bulk import: a zip of TSV spreadsheets, which is converted into a package first (Graphic_Data_Transfer_Tsv). Its links to existing content become the suggested link choices, and its Interactive figures are marked for their saved figure to be built in the browser with their HTML.
