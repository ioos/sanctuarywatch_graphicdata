class-figure-html-rebuild.php

Rebuild of standalone figure HTML.

Each published Figure has two standalone HTML files in wp-content/data/figure_<ID>/: figure-<ID>.html (with title, links and captions; its URL is stored in figure_iframe_code) and figure-<ID>_figure_only.html. The Figure edit screen writes them in the browser when a Figure is saved (createFigureHtml() in admin/js/figure-html.js).

Figures created by the Content Transfer importer never pass through the edit screen, so they are queued here and the Content Transfer page builds their HTML in the browser with the same createFigureHtml(), from each Figure's saved content (for Interactive figures, the saved Plotly JSON in figure_interactive_args_rendered, as on the frontend). Administrators can also rebuild every Figure, or every Figure in an Instance, for example after the site moves to a new domain.

Which Figures get HTML follows the edit screen: only Figures whose Status is Published, and Interactive figures only once they have saved JSON.

Interactive figures from a bulk import (Graphic_Data_Transfer_Tsv) have settings and data but no saved JSON yet. They are marked with RENDER_META_KEY, and the browser first builds their saved JSON from the settings with the edit screen's chart, table and map code (see save_render()), then their HTML.
