class-transfer-tsv.php

Bulk import from tab-delimited spreadsheets (TSV) for the Content Transfer tool.

A bulk import is a zip holding one TSV file per content type (instance_types.tsv, instances.tsv, scenes.tsv, modals.tsv, figures.tsv), plus media/ and data/ folders for the files the rows refer to. Pages and the About content are not part of a bulk import.

The zip is converted into an ordinary Content Transfer package (see Graphic_Data_Transfer_Exporter) and imported by Graphic_Data_Transfer_Importer, so a bulk import is checked, linked, undone and gets its figure HTML exactly like any other import.

The columns are the fields of each content type's edit screen (from its create_*_fields() definition), limited to the fields that the transfer tool moves (Graphic_Data_Transfer_Schema::get_meta_keys()). Values are cleaned the way the edit screen cleans them, blank cells take the field's default, and fixed choices are checked. The template download and its README.tsv are generated from the same definitions.

Cells that point at other content:

  • Links to Instances, Scenes and Modals take ref: (the ref of a row in this bulk import), or id:<ID> / slug: of existing content. Links to existing content are offered as the suggested link on the import screen.
  • Image cells take media/ (a file in the zip), an https:// address (downloaded) or attachment:<ID> (already in the Media Library).
  • figure_upload_file takes data/: a CSV (converted to JSON as on the Figure edit screen), JSON or GeoJSON file.
  • figure_interactive_arguments takes an Interactive figure's settings as JSON (the edit screen's "Copy settings for bulk import" button). The settings are checked against the data; a figure whose settings cannot be used is imported with its Status set to Draft and listed. The saved figure is built in the browser after the import, like its HTML (see Graphic_Data_Figure_Html_Rebuild).
