class-transfer-tsv-exporter.php

Export to tab-delimited spreadsheets (TSV) for the Content Transfer tool.

Writes the content that Graphic_Data_Transfer_Exporter collects as a bulk import zip (see Graphic_Data_Transfer_Tsv): one TSV file per content type, README.tsv, and media/ and data/ folders. The files can be edited in a spreadsheet and uploaded again in the Import section.

Each cell is written so that the bulk import reads back the value that was exported:

  • Every row gets a ref (-<source ID>, or type-<term ID> for Instance Types). Links to exported rows are ref:; links to other content are slug:, which also finds it on another site.
  • Images in the Media Library or uploads folder are written to media/; other image addresses are kept, and the import downloads them.
  • A figure's data file is written to data/: its CSV file when that converts to the JSON the figure uses, otherwise the JSON (or GeoJSON).
  • Backslashes in text cells are doubled, since the import reads \n, \t and \ there as escapes.

Spreadsheets carry less than a package. Pages and the About content are left out, images inside formatted text are not included, an Interactive figure's chart is rebuilt from its settings on import, and an import creates new content rather than updating what was exported. The preview lists what applies to the selection.
